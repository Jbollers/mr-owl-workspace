# Teaching with Mr. Owl

Start with the pinned Teaching Studio card. Drop source files in inbox, then give their paths to a Codex or Claude chat.

| Request | Skill |
| --- | --- |
| Plan a lesson | $elementary-lesson-plan-builder |
| Format a plan | $lesson-plan-template-formatter |
| Adapt a deck | $powerpoint-lesson-editor |
| Add teacher notes | $powerpoint-teacher-notes-generator |
| Bring it indoors | $shorten-lesson-deck |

Prefer powerpoint-lesson-editor for general shortening, and powerpoint-teacher-notes-generator for notes only. The older shorten-lesson-deck workflow is retained for indoor adaptations; the current preference for minutes per activity overrides its cumulative clock convention.

Read sources before proposing cuts. Never imply a whole unit assessment is covered by one shortened lesson. Confirm actual file-tool availability; do not claim a deck was edited when only instructions were drafted. Save revised files separately, verify content and rendered layout, and register completed work in workspace/workspace.json.
