# PowerPoint Teacher Notes Generator

## Inputs

Read the actual deck, original notes, guide or plan, grade, activity boundaries and any agreed pacing. If sources conflict, follow the current request and disclose the discrepancy. If only a deck is supplied, distinguish inferred teaching suggestions from source requirements.

## Workflow and rules

Write notes a teacher can use while presenting: Activity and approximate minutes, Do, Say, Ask, Look For, and If Scholars Struggle where useful. Add student expectations, a likely misconception or a back-pocket question when relevant. Avoid repeating all slide text or turning each note into an essay. Keep source links and useful original teaching cautions.

Use minutes per activity, never elapsed clock time unless explicitly requested. On an activity spanning several slides, put the duration on the start slide; label following slides as continuation with no added time. Keep an internal activity-to-slide map. Include transition time in the agreed activity budget.

Keep prompts aligned with visible materials and the stage of learning. Do not reveal a conclusion before students investigate it. Distinguish acceptable evidence from exact wording students must imitate. Preserve the deck's content, order, design and animations for notes-only work.

Use the available presentations skill for writing and inspecting notes. Save a new PPTX. If notes cannot be embedded with available tools, provide a slide-indexed notes document and state that the deck is unchanged.

## Outputs

A new PPTX with embedded speaker notes and a concise pacing summary. A notes-only document is a disclosed fallback, not a claim of completed deck editing.

## Validation

Read notes back from the saved file and verify every intended slide has the correct notes, activity continuations are clear, unique activity minutes sum correctly, prompts refer to visible content, and existing resource links survive. For notes-only changes, check slide content and order remain unchanged; inspect rendered slides if the editing tool rewrites them.

## Related skills and handoff

If duration requires removing or condensing content, pass the deck, guide and pacing conflict to $powerpoint-lesson-editor only when scope includes deck editing; otherwise report the conflict. Use $elementary-lesson-plan-builder only for requested substantive planning gaps.

Use related skills only when available and within the current request. Pass concrete inputs and unresolved constraints; do not assume a named skill can invoke itself or that tools are installed. If a dependency is unavailable, use an appropriate available workflow or clearly identify the blocked deliverable. Current user instructions and supplied references override historical defaults.
