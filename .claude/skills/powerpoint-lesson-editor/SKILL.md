# 30/45-Minute PowerPoint Lesson Editor

## Inputs

Inspect the deck, speaker notes, teacher guide, student assignment, target minutes and classroom constraints. Use 30 minutes as a disclosed default only when no duration is stated. If a guide is missing, request it for curriculum-faithful decisions; a deck-only draft must identify unverified assignment and assessment dependencies.

## Workflow and rules

Inspect every slide, including image-only directions. Map original slide number to purpose, assignment dependency, assessment foundation, next-lesson dependency and keep/condense/remove decision. Keep the learning question, essential context, recording instructions, examples, vocabulary, practice and checks needed for student success. Do not imply this lesson teaches later assessment content absent from the guide.

Condense repetition and lengthy sharing before cutting student work. Preserve conceptual order and move essential material to a retained slide or notes before removing its source. Choose slide count from instructional needs. Preserve original visual design, dimensions, editable objects, images and useful links; save a new copy.

For indoor adaptation requests, reuse suitable classroom materials or source images first. Label new activities as adaptations. Update dependent slide text, image-based directions, materials, notebook instructions and notes. A photograph cannot supply touch, smell or measurements not present in the image. Explain any change to what students can observe.

Budget minutes per activity, including setup, transitions, practice and closing. Count shared activities once. The user's reviewed preference is activity duration, not elapsed clock ranges; this supersedes older timing conventions for work performed with this skill. Use available presentations tooling for editing and rendering. If unavailable, deliver a proposed edit map and clearly state that no PPTX was edited.

## Outputs

A new editable PPTX, a concise original-to-final slide map with reasons for cuts or combinations, and activity pacing totaling the requested duration. Keep scratch files out of delivery.

## Validation

Reopen the saved deck; verify slide order, assignment support, updated notes, image-based directions, activity totals and obsolete labels. Render all final slides and inspect for clipping, font changes and unintended design loss. Confirm there is realistic work time, not merely a plausible slide count.

## Related skills and handoff

For requested teaching notes or notes needed to make the shortened deck teachable, use $powerpoint-teacher-notes-generator with the final slide map, guide, activity IDs and timing budget. Let the editor own pacing decisions so the notes generator cannot double-count time. Use this skill explicitly when distinguishing it from the separately installed legacy shorten-lesson-deck skill.

Use related skills only when available and within the current request. Pass concrete inputs and unresolved constraints; do not assume a named skill can invoke itself or that tools are installed. If a dependency is unavailable, use an appropriate available workflow or clearly identify the blocked deliverable. Current user instructions and supplied references override historical defaults.
