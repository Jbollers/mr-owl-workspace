# Elementary Lesson Plan Builder

## Inputs

Use the supplied source, grade, objective, duration, materials, assignment and assessment criteria. Recover referenced attachments when available. Ask for a missing source when source-faithful adaptation depends on it. For topic-only requests, identify the result as an original draft and label assumptions; do not invent curriculum alignment.

## Workflow and rules

Read the objective, sequence, student task, stopping points and assessment before drafting. Preserve conceptual development and the evidence students must produce. Cite source pages or sections for consequential requirements; separate source content from proposed additions.

Use the preferred structure when no different format is requested: Objective/Scholar Goal, Materials, Important Words, then activity blocks containing Do, Say, Ask, Look For, If Scholars Struggle, and Closing. Use clear teacher directions and age-appropriate language addressed to scholars. Add concise back-pocket questions, plausible exemplars, misconceptions and scaffolds only where they serve the objective; label inferred examples instead of attributing them to the source.

Allocate minutes to activities, including transitions, practice and a closing check. Count a multi-part activity once. Protect student work rather than filling the plan with teacher talk. Do not change the grade, objective or assessment to fit a prettier format. Use only supplied standards identifiers or verify an explicitly requested alignment against the relevant official standards.

## Outputs

An editable teacher-facing plan in the requested format, with activity minutes, source/adaptation distinctions and a brief list of material assumptions. Deliver inline if no file is requested. Use available document or PDF workflows when those file types are requested.

## Validation

Check that every objective has an observable check, every assignment has necessary directions and materials, vocabulary supports the task, and activity minutes sum to the requested duration. Verify exemplars against the source and preserve required stopping points. State missing evidence rather than asserting unsupported assessment coverage.

## Related skills and handoff

For formatting an approved plan, pass the plan, sources, timing and template to $lesson-plan-template-formatter. For an existing deck needing cuts, pass the plan, deck, guide and protected objectives to $powerpoint-lesson-editor. Do not create those extra products unless requested.

Use related skills only when available and within the current request. Pass concrete inputs and unresolved constraints; do not assume a named skill can invoke itself or that tools are installed. If a dependency is unavailable, use an appropriate available workflow or clearly identify the blocked deliverable. Current user instructions and supplied references override historical defaults.
