# Lesson Plan Template Formatter

## Inputs

Use the approved lesson text and requested output format. Inspect the actual reference template when supplied, including headers, page size, styles, tables and spacing. Without it, offer a usable approximation with disclosed assumptions rather than claiming an exact match.

## Workflow and rules

Treat content as the source of truth. Map each objective, activity, prompt, scaffold and assessment into the target sections before changing layout. Preserve timing, order, student directions, exemplars and source references. Flag absent content instead of filling it with invented curriculum.

The history supports a Mr. Bollers header, objective section, timed sections, red section bars, teacher prompts, Ask, Look For and Back-Pocket Questions. Use these as defaults only when no current template overrides them. RedThread-style and simplified science layouts are possible styles, not stored templates: exact matching requires a supplied reference. Do not fabricate school, date, standards codes or logos.

Use document styles and editable text. Keep activity headings with their prompts, avoid splitting short teaching blocks across pages, and make print contrast readable. Use the available documents skill for DOCX and pdf skill for PDF work, following their rendering workflow. If those tools are unavailable, provide structured text and identify the file-format limitation. Do not replace this task with Template Creator.

## Outputs

The formatted plan in the requested editable format, plus PDF only if requested. Briefly identify any approximated design elements or unresolved missing sections.

## Validation

Compare the finished content against the input for omissions and unintended changes. Check time totals remain unchanged, prompts stay with the right activity, header fields are accurate, and all pages render without clipping or orphaned section labels. Do not claim a visual match without viewing both reference and output.

## Related skills and handoff

If substantive lesson gaps need work, pass specific missing sections and source material to $elementary-lesson-plan-builder within the requested scope. Return approved content to this formatter afterward. Formatting alone does not authorize curriculum revision.

Use related skills only when available and within the current request. Pass concrete inputs and unresolved constraints; do not assume a named skill can invoke itself or that tools are installed. If a dependency is unavailable, use an appropriate available workflow or clearly identify the blocked deliverable. Current user instructions and supplied references override historical defaults.
