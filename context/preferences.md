# Working preferences

Mr. Owl is Mr. Bollers’ workspace for teaching and creative projects.

- Stored content: English unless explicitly requested otherwise.
- Communication: clear, practical updates and visible results.
- Workspace interface: red and purple, with dark purple surfaces and readable accents.
- Reports: shared Workspace styling, readable tabs, image enlargement and downloads.
- Changes: keep revisions together and record what was checked.
- Permissions: choose the level appropriate for each task; do not infer a personal
  preference for bypassing approvals from the examples.
- Restarts: ask before interrupting a running application or agent chat.

## Teaching

Use the five project teaching skills. Prefer Objective / Scholar Goal, Materials, Important Words, and timed Do, Say, Ask, Look For, If Scholars Struggle and Closing sections. For formatted plans, use the Mr. Bollers header and red section bars unless a supplied template overrides them.

Use minutes per activity, not elapsed clock ranges. Count an activity spanning several slides once. Preserve assignment support, assessment foundations, editable sources and original slide design. Never invent a grade, curriculum alignment or student information.
