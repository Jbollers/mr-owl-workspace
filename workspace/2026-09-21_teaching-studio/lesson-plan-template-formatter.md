# Format a plan

Put approved content into your teacher-facing layout.

## Bring to the nest

An approved lesson plan, output format and any reference template.

## Start with this prompt

Copy this into a Codex or Claude chat, replace the bracketed details, and attach your source files.

> Use $lesson-plan-template-formatter to format my approved plan with a Mr. Bollers header, objective section, timed activities, red section bars, Ask, Look For and Back-Pocket Questions. Preserve all content and timing. Use my attached reference for an exact match, or identify the layout as an approximation.

## What you get

A readable, editable plan; no invented curriculum or silently changed pacing.

## Mr. Bollers' teaching checks

- Use clear directions addressed to scholars.
- Keep source requirements separate from proposed additions.
- Protect practice and observable evidence of learning.
- Count each activity once, including transitions and closing.
- Verify saved files and previews before calling a deliverable finished.

The project skill is available in the desktop Skills panel for both Codex and Claude. File generation requires the relevant document or presentation tools in that agent session; if unavailable, the agent must disclose a draft-only fallback.
